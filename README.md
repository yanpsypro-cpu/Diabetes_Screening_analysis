# Diabetes screening programme analysis

This repository contains the R scripts and figures used in a statistical
analysis of a fictitious diabetes screening programme.

## Files

### R scripts

- `R/task1_descriptive.R` contains the data checks, descriptive summaries and
  figures used for Task 1.
- `R/task2_analysis.R` contains the hypothesis tests, effect estimates,
  stratified analyses and figures used for Task 2.

### Figures

The `figures` directory contains the descriptive and inferential figures
generated by the R scripts. The final report uses a selected subset of these
figures.

## Reproducibility

The scripts were written in R. The Task 2 analysis uses the `Epi` package for
two by two table analysis.

The dataset is not included because it was supplied for the assessment.
To reproduce the analysis, place the authorised data file in the working
directory and update the input and output paths at the beginning of each
script if necessary.
